# 배송 현황 카드 컴포넌트 구현

## 프로젝트 스택
- React + TypeScript + Vite
- Tailwind CSS + styled-components (스타일링은 자유 선택)
- lucide-react (아이콘)
- TanStack Router (라우팅)

## 구현 목표
물류 운영팀 내부 대시보드용 배송 현황 카드 컴포넌트.
하루 수백~수천 건 모니터링 환경이므로 정보의 빠른 인식과 상태 구분이 핵심.

## 배송 상태 (5가지)
- 배송 준비 중
- 배송 중
- 배송 완료
- 배송 지연
- 반송

## 필수 구현 항목
1. 카드에 표시할 핵심 정보
   - 송장번호
   - 수령인
   - 출발지 / 도착지
   - 예상 도착일

2. 상태별 시각적 구분
   - 상태마다 색상 + 아이콘으로 명확히 구분
   - 상태값은 상수/테마 변수로 관리 (하드코딩 금지)

3. 타임라인 UI
   - 배송 단계를 순서대로 표현

4. 인터랙션
   - 카드 클릭 시 상세 정보 확장(Expand) 또는 모달 — 둘 중 적절한 방향 제안 후 진행

## 선택 구현 항목 (우선순위 순)
1. 배송 지연 시 경고 강조 처리
2. 카드 목록 렌더링 + 상태 필터
3. 로딩 Skeleton UI
4. 애니메이션 / 마이크로 인터랙션

## 코드 품질 기준
- Props 및 내부 state 타입 명시
- 상태별 렌더링 분기 명확하게 구조화
- 상수/테마 변수 활용, 하드코딩 최소화
- 불필요한 리렌더링 방지 (useMemo, useCallback 등)
